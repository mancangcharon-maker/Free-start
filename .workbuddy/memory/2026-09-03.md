# 2026-09-03

## SafeLift 外贸独立站改造 (Hexo + Cloudflare Pages)

### 任务
按照 `Desktop/SafeLift 升降平台外贸独立站原型.html` 的设计，把现有的 Hexo 博客（基于 laomingong.com 教程搭建 + Cloudflare Pages 部署）改造成工业风 B2B 外贸站。

### 关键决定
- **新建独立主题** `themes/safelift-modern/`（不重写已有的 butterfly-style `safelift-theme`），主题名改用新主题。
- **多页架构** 而非 SPA：保留 Hexo 的 4 个独立 page（Home/Products/About/Contact）+ 1 个 product 详情布局，每个页面独立 URL（对 SEO 友好）。
- 用 EJS 模板（hexo 默认引擎），用 front-matter `layout: <name>` 切换。

### 主要文件
- `themes/safelift-modern/layout/layout.ejs` — 公共布局（head + 固定顶部 nav + footer + 脚本）
- `themes/safelift-modern/layout/index.ejs` — 首页（Hero + 4 类别 + Why + CTA）
- `themes/safelift-modern/layout/products.ejs` — 产品列表（用 site.posts 动态生成，fallback 硬编码）
- `themes/safelift-modern/layout/product.ejs` — 产品详情（gallery + 价格 + features + specs_table + applications）
- `themes/safelift-modern/layout/about.ejs`、`contact.ejs`、`page.ejs`、`post.ejs`
- `themes/safelift-modern/source/css/safelift.css` — 完整移植原型 CSS（含响应式）
- `themes/safelift-modern/source/js/main.js` — 移动 nav、scroll 高亮、锚点平滑滚动、表单 demo
- `themes/safelift-modern/source/img/favicon.svg`

### 内容文件
- `source/products/index.md` `source/about/index.md` `source/contact/index.md` — 3 个 page
- `source/_posts/scissor-lift-10m.md` `boom-lift-16m.md` `dock-ramp-10t.md` — 3 个产品详情（用 front-matter 携带 model/price/specs_table/applications 等结构化数据）
- 删除了 `source/index/index.md`（与默认 home 冲突）和 3 个 demo post

### 修改
- `_config.yml` — `theme: safelift-modern`，`title: SafeLift`

### 关键问题与修复
1. **category 字段**：hexo 的 post 把 `category:` 单数字段转成 `categories` 数组。在模板里用 `p.categories.first().name` 兜底读取。
2. **hero 与 products/about/contact 顶 banner 被 fixed nav 遮挡**：给 .hero / .products-hero / .about-hero / .contact-hero 加 `margin-top: -68px; padding-top: 128px`，让 nav 浮在上面。
3. **hexo bin 脚本不能用 node 跑**：bin/hexo 是 shell 脚本，会被误执行。命令需走 `node_modules/.bin/hexo.cmd` 通过 PowerShell。
