### 踩坑记录（重要）
- **hexo deployer（hexo d）在此环境失败**：deployer 每次清空重建 `.deploy_git`，其 git 子进程在无终端环境无法交互认证（could not read Username / /dev/tty），且重建后 remote 为空、非 fast-forward 会被拒。
  - **可用替代**：手动流程 = `git clone --depth 1 --branch gh-pages <repo> <tmp>` → `git rm -rq .` → `cp -a public/. .` → `git add -A && git commit && git push origin HEAD:gh-pages`（在 Git Bash 里认证可用）。用完用 `git clean -ffd -- <tmp>` 删除。

- Bash 环境缺 `sleep`/`seq`，/tmp 不可写 —— 轮询/落盘要换 PowerShell Start-Sleep 或写项目内文件。

### 22:40 修复 "数据库未初始化 Database not initialized" 导致邮箱主页打不开
- **根因**：直改 D1 设置表后清除了 KV 缓存 key `setting:`，但 cloud-mail 的 `settingService.query()` 优先读 KV，KV 缺失直接抛 `数据库未初始化 Database not initialized.`（code 501）。
- **修复**：调用 `/api/init/<jwt_secret>`（idempotent），init 末尾会执行 `settingService.refresh(c)` 把 D1 当前设置重新写入 KV。
- **验证**：`curl https://mail.safelift.de5.net/api/setting/websiteConfig` 已从 code 501 变为 code 200，返回正常 domainList/注册/发信等配置；邮箱主页应可正常加载。
- **教训**：以后需要清 KV 让 D1 改动生效时，清完后必须重新触发 init 或调用 refresh 接口，不能只删 KV。
